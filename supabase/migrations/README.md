# ⚠️ Legacy migrations — do NOT apply to the GMI-ops backend

These SQL migrations were generated by Lovable and applied to the app's
**original** Supabase project. As of 2026-06-11 this web app was migrated to the
**GMI-ops** Supabase backend (`qdzgkttiosahdfqresvz`), which is the single source
of truth shared with the iOS app.

- The GMI-ops schema is managed from the iOS repo: `GMI/sql/*.sql`.
- These files reference the old table name `user_building_assignments`; GMI-ops
  uses `user_buildings`.
- **Do not run `supabase db push` against GMI-ops** — it would conflict with the
  live schema. Make schema changes via `GMI/sql/` and the Management API instead.

Kept for historical reference only.
